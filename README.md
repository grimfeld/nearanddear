# Near & Dear

Collaborate on curated maps with your team. This project uses Vite, React, and Supabase.

## Map Collaboration Invites

Map owners can generate shareable invite links that let collaborators join a map. The invite link works for existing accounts as well as new users (they’ll be prompted to sign in or create an account before joining).

## Development

Install dependencies and start the Vite dev server:

```bash
npm install
npm run dev
```

## Testing

Run the Playwright test suite:

```bash
npm run test:e2e
```
